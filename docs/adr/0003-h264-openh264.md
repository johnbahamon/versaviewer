# ADR-0003: H.264 con OpenH264 por software en la Fase 0

- Estado: Aceptado para la Fase 0 (2026-11-22)

## Decisión
H.264 Constrained Baseline con OpenH264 (crate `openh264`, compilado desde
fuente) en el agente y el viewer, `UsageType::ScreenContentRealTime`.

## Motivos
- Compila en todas las plataformas sin dependencias del sistema.
- Perfil universalmente negociable en WebRTC; decodificable por hardware en cualquier cliente.
- Licencia BSD; Cisco cubre las regalías de los binarios que distribuye
  (para distribución propia del código fuente compilado hay que revisar la licencia de patentes antes de comercializar).

## Consecuencias
- ~15–25 fps a 1080p en CPU. La Fase 1 añade encoders hardware (Media
  Foundation/NVENC/QSV, VideoToolbox) detrás de la misma API de `vv-codec`, y
  evaluará AV1/VP9 para contenido de pantalla.
